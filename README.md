# AGC Travel

Working hub for HTML tools and artifacts built for the AGC ServiceNow project (Travel and HR tracks).

## Structure

- `index.html` — hub page linking to everything below
- `timelines/` — interactive release/sprint timeline tools
- `backlogs/` — user story / backlog documents
- `discovery/` — individual write-ups per discovery session (one HTML file per session)

## Current contents

- `timelines/travel-release-timeline.html` — Travel track release timeline (Overview / R3 Sprint Plan / R3 Scope tabs, editable in-browser)
- `timelines/hr-roadmap-mockup.html` — HR track sprint roadmap redesign concept
- `timelines/release-roadmap-preview.html` — combined HR + Travel release-level roadmap concept
- `backlogs/travel-backlog.html` — Travel Arrangements (R2) user story backlog with Fibonacci estimates
